# WME COL Basemap

This script requires a userscript manager such as TamperMonkey:
[![Tampermonkey](https://img.shields.io/badge/TamperMonkey-Install-4caf50?style=for-the-badge&logo=tampermonkey)](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

Basemap overlay of the City of Lewisville GIS aerials (maps.cityoflewisville.com) - often features more recent aerial imagery than other sources

**Note:** please do not use as your default basemap - only enable when needed, as we 
do not want to abuse the service provided by the City of Lewisville GIS.

-------

### User's Guide

To enable the basemap, look in the layers sidepanel under the display section
or choose a shortcut to toggle the layer.

When the layer is enabled, at the top left of the map there is a date selector
to choose historical imagery. This will default to the most recent imagery date,
but you can choose to view older imagery when available.
